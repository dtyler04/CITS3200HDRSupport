System Information
How Weekly Digest Works:
  • Emails are sent every Monday at 9:00 AM
  • Students receive messages scheduled for their current week
  • Messages are personalized with student details
  • Only verified users receive digest emails
  • Messages are filtered by degree code and targeting
Message Targeting:
  • Degree Code: Must match student's degree
  • Week Released: Must match student's current week
  • Degree Type: Filtered if specified (PhD, Masters, etc.)
  • Location: Filtered if specified (Perth, Albany, etc.)
  • Stage: Filtered if specified (Coursework, Thesis, etc.)
